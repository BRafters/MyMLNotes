When we think about how we can assign a slope and intercept to a set of points, we have to define what the **best fit** is

- For each data point, we calculate **Loss**
    - It’s a number that measures how bad the model’s prediction was
    - Also referred to as ***Error***
- We think of **Loss** as the squared distance from the point to the line
- We do the squared distance (instead of just the distance) so that points above and below the line both contribute to total Loss in the same way
![[points.svg]]￼
- For point A, the squared distance is 9 (3^2)
- For point B, the squared distance is 1 (1^2)
- Add the squared distances together, and we have 10 as the total loss
    - If we had less loss than 10, that line would be a better fit for the data

The goal of **Linear Regression** is to find the slope and intercept that minimizes loss on average across all of the data
